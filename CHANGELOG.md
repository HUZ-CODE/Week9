# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-24

### Added
- Initial project setup with HTML, CSS, and JavaScript
- Book catalog with 9 featured books
- Advanced filtering system:
  - Filter by category (Fiction, Non-Fiction, Mystery, Sci-Fi, Romance, Biography)
  - Filter by price range (Under $20, $20-$50, $50-$100, Over $100)
  - Filter by rating (3+, 4+, 5 Stars)
- Search functionality by title, author, or category
- Sorting options:
  - Price (Low to High / High to Low)
  - Highest Rating
  - Newest First
- Shopping cart with:
  - Add/remove items
  - Quantity adjustment
  - Cart summary with subtotal, tax, and total
  - Real-time cart counter in navbar
- Toast notifications for user actions
- Responsive design for mobile, tablet, and desktop
- Professional UI with gradients and smooth animations
- Bootstrap 5 integration for responsive grid layout
- Font Awesome icons for enhanced UX
- Complete project documentation (README.md)
- Package metadata (package.json)
- Git configuration (.gitignore)

### Features
- Clean, maintainable code structure
- Vanilla JavaScript (ES6+) without external dependencies for logic
- CSS3 animations and transitions
- Mobile-first responsive design
- Accessible HTML structure
